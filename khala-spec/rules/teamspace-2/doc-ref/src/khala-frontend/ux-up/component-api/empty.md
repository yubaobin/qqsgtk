## Empty的 API
### Empty 属性

|属性名|说明|类型|默认值|
|-----------|-----------------|---------|---|
|image|empty组件的图像地址|string|''|
|image-size|empty组件的图像尺寸（宽度）|number|—|
|description|empty组件的描述信息|string|''|

### Empty 插槽

|插槽名|说明|
|-----------|---------|
|default|作为底部内容的内容|
|image|作为图像的内容|
|description|作为描述的内容|
