## Text的API
### 属性

|属性名|说明|类型|默认值|
|-------------------|-------|--------------------|-------|
|type|类型|'primary'\|'success'\|'warning'\|'danger'\|'info'|—|
|size|大小|'large'\|'default'\|'small'\|'mini'|default|
|truncated|显示省略号|boolean|false|
|line-clamp|最大行数|string/number|—|
|tag|自定义元素标签|string|span|
