## Divider的 API
### Divider 属性

|属性名|说明|类型|默认值|
|----------------|-----------|------------------|----------|
|direction|设置分割线方向|'horizontal'\|'vertical'|horizontal|
|border-style|设置分隔符样式[css/border-style](https://developer.mozilla.org/zh-CN/docs/Web/CSS/border-style)|'none'\|'solid'\|'hidden'\|'dashed'|solid|
|content-position|自定义分隔线内容的位置|'left'\|'right'\|'center'|center|

### Divider 插槽

|插槽名|说明|
|-------|----------|
|default|设置分割线文案的位置|
