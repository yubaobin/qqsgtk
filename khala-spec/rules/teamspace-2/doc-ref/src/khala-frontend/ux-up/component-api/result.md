## Result的 API
### Result 属性

|属性名|说明|类型|默认值|
|---------|--------------|-----|----|
|title|result组件的标题|string|''|
|sub-title|result组件的副标题|string|''|
|icon|result组件的图标类型|enum`'primary'(1.1.4)\|'success'\|'warning'\|'info'\|'error'`|info|

### Result 插槽

|名称|说明|
|---------|----------------|
|icon|icon内容|
|title|resulttitle的内容|
|sub-title|subtitle的内容|
|extra|内容额外区域的内容|
