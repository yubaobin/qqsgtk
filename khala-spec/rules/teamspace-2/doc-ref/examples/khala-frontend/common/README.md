# Khala 前端场景通用示例

本目录包含 9 个 Khala 前端开发场景的**跨版本通用代码示例**。已更新的样例（如 `api/definition/`、`api/usage/`）已从场景级子目录调整到对应场景的 `common/` 内。

## 场景清单

| 场景 | 目录 | 说明 |
|------|------|------|
| 标准 CRUD 页面 | crud-page/ | 列表页、新增编辑弹窗 |
| API 接口 | api/ | API 模块定义（含 definition/、usage/） |
| 字典使用 | dict/ | 动态字典下拉列表 |
| 图标使用 | icon/ | 图标引入与渲染 |
| Pinia Store | store/ | Store 定义 |
| Vue Bus | event-bus/ | 跨组件事件通信 |
| Mock 数据 | mock/ | Mock 数据模拟（index.mock.js、json.js） |
| 样式 | styles/ | SCSS 样式（cover-ux.scss、use-scss.scss） |
| 文件上传 | upload/ | 上传组件示例（upload-file.vue、upload-image.vue） |
