# security — 安全防护

> **适用版本**: 7.x+
> **最后更新**: 2026-06-08
> **相关规范**: .rules/backend/khala-core.md
> **相关源码**: doc-ref/security/

## 何时参考此示例

- 需要统一安全策略防止 Web 攻击
- 需要 XSS 过滤、SQL 注入防护
- 需要接口签名验证和请求加密解密
- 需要数据脱敏、敏感操作保护
