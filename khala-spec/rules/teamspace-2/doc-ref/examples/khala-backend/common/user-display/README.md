# user-display — 用户数据翻译

> **适用版本**: 7.x+
> **最后更新**: 2026-06-08
> **相关规范**: .rules/backend/khala-core.md
> **相关源码**: doc-ref/user-display/

## 何时参考此示例

- 列表查询需要展示创建人、更新人等用户名称，但数据库仅存储用户 ID
- 需要将租户 ID 翻译为租户名称
- 希望减少前端请求次数，由后端统一完成数据翻译
