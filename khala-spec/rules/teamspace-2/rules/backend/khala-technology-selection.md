# Khala 技术选型指南

## 1. 前端框架

### Khala-frontend-vue3 7.x

基于 Vue 3 的前端开发框架，提供组件化开发模式和响应式数据绑定。

**特点：**

- 组件化开发模式，提高代码复用性
- 响应式数据绑定，简化状态管理
- 生态系统完善，配套工具丰富

**适用业务场景：**

- 适用通用业务场景
- 企业级管理系统、后台管理平台
- 数据可视化大屏展示系统
- 中小型电商、门户网站前端
- 移动端H5应用开发

### Vue3

基于 Vue 3 的开源前端框架，提供组件化开发模式和响应式数据绑定。

**特点：**

- 组件化开发模式，提高代码复用性
- 响应式数据绑定，简化状态管理
- Composition API，提升逻辑复用和代码组织能力
- 生态系统丰富，可灵活搭配 UI 组件库

**适用业务场景：**

- 适用通用业务场景
- 不需要公司统一前端框架的自定义项目
- 需要更灵活的前端技术选型
- 对前端框架版本有特定要求的项目

## 2. 后端框架

### Khala-backend 7.x

通用后端服务框架，支持 RESTful API 开发和业务逻辑处理。

**特点：**

- 通用架构设计，适用多种业务场景
- 原生支持 RESTful API 开发
- 内置业务逻辑处理能力

**适用业务场景：**

- 适用通用业务场景
- 企业级业务系统后端服务
- RESTful API 接口服务
- 微服务架构中的业务服务
- 数据中台、业务中台建设

### Spring Boot 3.5.x

基于 Spring Boot 3.5.x 的开源后端框架，提供自动配置、嵌入式服务器和生产级特性支持。

**特点：**

- 自动配置，简化 Spring 应用开发
- 嵌入式服务器，开箱即用
- 生产级特性（健康检查、指标监控、外部化配置）
- 支持 Java 17+ 和 GraalVM 原生编译

**适用业务场景：**

- 适用通用业务场景
- 不需要公司统一后端框架的自定义项目
- 需要最新 Spring Boot 版本特性的项目
- 对 Java 版本有特定要求（Java 17+）的项目

## 10. 大数据

### Hadoop

Apache 基金会开源的分布式存储与计算框架，提供 HDFS 分布式存储和 MapReduce 分布式计算能力，是大数据生态的基础设施。

**特点：**

- HDFS 高可靠分布式存储
- MapReduce 批处理计算模型
- 生态完善，组件丰富
- 支持海量数据离线处理

**适用业务场景：**

- 适用通用业务场景
- 海量数据离线批处理
- 数据湖存储底座
- 日志归档与历史数据分析
- 大规模数据ETL处理

### Spark

Apache 基金会开源的基于内存的分布式计算引擎，支持批处理、流处理、机器学习和图计算。

**特点：**

- 基于内存计算，性能优于 MapReduce
- 统一引擎支持批流一体
- 丰富的生态组件（SQL、MLlib、GraphX、Structured Streaming）
- 支持多种数据源和部署模式

**适用业务场景：**

- 适用通用业务场景
- 大规模数据批处理和ETL
- 交互式数据分析（Spark SQL）
- 机器学习模型训练
- 实时流数据处理（Structured Streaming）

### Flink

Apache 基金会开源的分布式流处理框架，支持有状态计算和精确一次语义，擅长低延迟实时处理。

**特点：**

- 低延迟流处理引擎
- 支持有状态计算和精确一次语义
- 批流一体架构
- 丰富的窗口和事件时间支持

**适用业务场景：**

- 适用通用业务场景
- 实时数据流处理和ETL
- 实时监控和告警
- 实时推荐和风控
- 事件驱动型应用

### Hive

基于 Hadoop 的数据仓库工具，提供类 SQL 查询语言（HQL），适合大规模数据的离线分析。

**特点：**

- 类 SQL 查询语言，降低使用门槛
- 建立在 Hadoop 之上，处理海量数据
- 支持多种存储格式和执行引擎
- 适合批处理离线分析

**适用业务场景：**

- 适用通用业务场景
- 数据仓库建设和离线报表
- 历史数据分析和挖掘
- 日志数据批量分析
- 数据集市建设

### ClickHouse

开源的高性能列式 OLAP 数据库，支持实时分析查询，单表查询性能卓越。

**特点：**

- 列式存储，查询性能极高

**特点：**

- 轻量级，部署简单
- 兼容 OpenTracing / Brave
- 支持多种存储后端（Elasticsearch、MySQL 等）
- 链路数据查询和依赖图展示

**适用业务场景：**

- 适用通用业务场景
- 轻量级链路追踪需求
- 延迟问题定位和分析
- 与 Spring Cloud Sleuth 集成的追踪场景
- 对资源占用敏感的追踪方案

### Prometheus + Grafana

Prometheus 为开源监控和告警系统，Grafana 为数据可视化和仪表盘平台，二者常配合使用。

**特点：**

- Prometheus 拉取式指标采集，配置灵活
- PromQL 强大查询语言
- Grafana 丰富的可视化图表和仪表盘
- 丰富的 Exporter 生态和告警规则

**适用业务场景：**

- 适用通用业务场景
- 基础设施和应用指标监控
- 容器和 Kubernetes 集群监控
- 业务指标看板和实时大屏
- 多维度告警和通知

### Zabbix

企业级开源监控平台，支持网络、服务器和应用的全面监控。

**特点：**

- 全面的监控能力（网络、系统、应用）
- 丰富的模板和自动发现
- 灵活的告警和通知机制
- 支持分布式监控架构

**适用业务场景：**

- 适用通用业务场景
- 传统IT基础设施监控
- 网络设备和服务器监控
- 数据库和中间件监控
- 需要成熟告警体系的企业监控

### Filebeat

Elastic 生态的轻量级日志采集器，负责采集和转发日志到 Elasticsearch 或 Logstash。

**特点：**

- 轻量级，资源占用少
- 支持多种日志输入源
- 内置日志解析和过滤
- 与 Elastic 生态无缝集成

**适用业务场景：**

- 适用通用业务场景
- 服务器和应用日志采集
- Elastic ELK 日志体系前端采集
- 容器日志收集
- 结构化和非结构化日志转发

### Fluentd

开源的统一日志采集和路由工具，支持丰富的输入输出插件。

**特点：**

- 统一日志采集、过滤和路由
- 插件生态丰富，支持 500+ 插件
- 支持多种数据源和输出目标
- Kubernetes 默认日志采集方案

**适用业务场景：**

- 适用通用业务场景
- 多源日志统一采集和路由
- Kubernetes 集群日志收集
- 日志清洗转换和多目标分发
- 云原生环境日志可观测性

## 15. 部署

### 物理机部署

传统部署方式，直接在物理服务器上运行应用服务。

**特点：**

- 无虚拟化开销
- 性能最优
- 运维复杂度高

**适用业务场景：**

- 适用通用业务场景
- 对性能要求极高的核心系统
- 数据库等IO密集型应用
- 传统IT基础设施环境
- 对硬件资源有特殊需求的系统

### 虚拟机部署

基于虚拟化技术，在物理服务器上通过虚拟机软件创建多个相互隔离的虚拟机的部署方式。

**特点：**

- 虚拟化隔离，环境互不影响
- 资源共享，提高物理资源利用率
- 运维简化，虚拟机创建和迁移方便
- 成本优化，减少物理服务器数量

**适用业务场景：**

- 适用通用业务场景
- 传统企业应用部署
- 需要环境隔离的多租户系统
- 测试和开发环境
- 资源利用率优化场景

### CCSE

电信自研的容器安全平台，提供容器运行时安全保障。

**特点：**

- 容器运行时安全
- 企业级安全保障
- 电信生态集成

**适用业务场景：**

- 电信业务场景首选
- 电信运营商容器化部署
- 对安全合规要求高的容器环境
- 电信云原生应用部署

### Docker + K8s

容器化部署方案，Docker 提供容器化，Kubernetes 提供编排管理。

**特点：**

- 容器化隔离
- 自动化编排
- 弹性伸缩能力

**适用业务场景：**

- 适用通用业务场景
- 微服务架构应用部署
- 需要弹性伸缩的互联网应用
- CI/CD持续集成部署
- 云原生应用开发和部署
