# OCR Frontend

Vue 3 frontend for the PaddleOCR image recognition system.

## Setup

```bash
cd frontend
npm install
```

## Run

```bash
npm run dev
```

The app runs on `http://localhost:5173`.

## Configuration

Set `VITE_API_BASE_URL` in a `.env` file to point to the backend (default: `http://localhost:8000`).
